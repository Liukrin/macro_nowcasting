# 已知局限

以下为项目数据与模型的已知局限。

## 1. 单季同比口径不可用
四川GDP累计值序列在2017/2018间存在第四次全国经济普查造成的vintage断点。
累计值差分得到的单季名义值跨断点后出现严重口径跳变(2017=13.16%, 2018=16.01%,
而官方实际增速8.1%/8.0%)。因此单季同比(qoq_yoy)口径已弃用。

## 2. feature_vintage未实现
当前所有特征使用季度完整数据(第t季度3个月全部可得)。
two_month/one_month的发布时滞模拟尚未实现。严格来说当前管道为同期回归(contemporaneous),
而非现时预测(nowcasting)。

## 3. target_lag_1未进入特征集
16特征cap下target_lag_1被四川/全国/PMI特征挤掉。
模型无法显式使用y_{t-1},缺少锚点。

## 4. chronos-2-small API不兼容
Chronos2Pipeline要求3D输入(n_series, n_variates, history_length),
而bolt系列接受2D(batch, length)。未适配。

## 5. 样本量限制
回测窗口数24-32,统计检验(DM)功效有限。小样本下即使真实预测能力存在,
也可能无法通过显著性检验。

## 6. 数据覆盖
- 国家月度数据截止2025-09(固定资产投资/工业增加值等)
- PMI截止2025-12
- 四川月度数据截止2025-12
- 2025Q4 GDP为估算值

## 7. 指标口径混杂
四川月度指标均为累计同比(ytd_yoy),国家月度含累计同比和当月同比(mom_yoy)两种。
混频建模中将两者纳入同一特征矩阵,口径差异可能引入噪声。

## 8. 方向准确率口径
last_value 预测的变化量恒为 0（所有窗口使用同一个 y_{t-1}），
其方向准确率等于"实际同比下降的窗口占比"，不作预测能力解读。
所有模型的方向准确率已改为与 0.5（随机猜测）比较并做二项检验。
小样本下（23 对方向比较）无一模型显著优于随机。

## 9. 常数偏差修正对 delta 残差无效的更正
原报告称"delta 残差均值为 0 是差分序列的自然性质"——此表述有误。
正确原因：带截距项的线性模型（ElasticNet 含截距），
其样本内拟合残差均值必然约等于 0。截距吸收了系统性偏差，
因此用样本内残差均值做常数修正等同于加 0，不起作用。

## 10. 共享可变状态（st.cache_resource）
load_view_data 与 load_engine 使用 @st.cache_resource，
返回的是跨会话共享的同一个对象引用，其 dict 与其中的 engine 会被所有会话共用。
- 本项目为单人演示场景，共享引擎可接受；
- 生产环境需改为每会话独立实例或加锁。

## 11. TF-IDF 词汇匹配局限
采用 char_wb n-gram (2,4) 的 TF-IDF 为纯词汇匹配，无法理解语义等价。
典型例子："四川的生产情况"无法关联到"规模以上工业增加值_累计同比"，
因为语料卡片文本不含"生产"一词。
语义检索（BGE等嵌入模型）可解此类语义鸿沟，
但本地嵌入权重不完整且会增加部署复杂度，暂未部署。

## 12. 跨区域 diversity re-ranking 缺失
search() 的合并排序仅按归一化 TF-IDF 分降序，不做跨区域多样性重排。
当查询同时提到四川和全国时（如"四川和全国比工业增速差多少"），
top-5 结果可能全部偏向一个区域，无法保证两个区域的结果都出现。
引入 MMR（Maximal Marginal Relevance）或按区域分层抽样可解。但当前检索
量级较小（top_k=5），实际影响有限，暂未实现。

## 13. demo 模式占位数据
- 仓库保留 sc_macro_agent/data/data_generator.py 作为 dataset_mode=demo
  的降级路径，生成 source_name="SyntheticGenerator" 的占位数据。
  该路径不参与任何已报告的回测与预测结果，全部指标均由真实数据产出。
