- YYYYMM格式整数 (201002等) 优先于Excel序列号检查
- 15行全NaN空行已清除

## 口径区分
- 固定资产投资额累计增长(%) → 累计同比 (ytd_yoy)
- 工业增加值同比增长(%) → 当月同比 (mom_yoy)
- 房地产投资/社消零售累计值 → 水平序列 (cum_level, 排除特征池)
- GDP_累计同比 → 指数转增速 (117.7→17.7%)
